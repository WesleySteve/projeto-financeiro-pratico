# Projeto: Gestão e Análise Financeira Empresarial ( Empresa fictícia )

## Nome: Prudente Distribuidora Ltda.

### Segmento: distribuição de produtos para mercados e pequenos varejistas.

#### O projeto vai simular uma empresa real, contendo:

- clientes;
- fornecedores;
- produtos;
- vendas;
- contas a receber;
- contas a pagar;
- pagamentos;
- recebimentos;
- movimentações bancárias;
- despesas;
- orçamento;
- fluxo de caixa;
